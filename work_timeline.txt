frontend component import api - this script has methods to do post request to server

frontend has the info, use it as arguments when calling the imported api methods.
api method do a fetch request, to server

our localhost 5000 is server. server gets this request
server imports the diff routes subscriptions
then links each route script to the url sent by the api

when the routes get the url, it sees whch controller method to calling

controller talks to database

full link: frontend -> api -> server -> routes -> controller -> db

the ONLY scripts that care about ur data is frontend  when calling api method AND controller
